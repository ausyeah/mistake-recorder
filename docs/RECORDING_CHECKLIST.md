# 录制与截图清单（README 演示素材）

> 本清单按 **README 展示顺序** 组织，产出素材后替换 `README.md` 中的占位符即可。
> 录制工具：手机自带录屏即可；截图建议 1080×2400（或 9:16），统一圆角与比例。
> ⚠️ **凡出现设置页 / API Key 的镜头，务必先打码或模糊处理密钥。**

---

## 一、录屏清单

| # | 内容 | 时长 | 说明与要点 | 对应 README 位置 |
|---|---|---|---|---|
| R1 | 安装与首次启动 | 30–60s | 下载 APK → 安装 → 首次启动 → 进入设置页。**不要录到真实 Key** | 「安装」 |
| R2 | 功能总览（演示） | 60–120s | 首页 → 拍照录入 → 裁剪框选题目 → 识别进度（上传/解析/整理）→ 编辑页 → 列表 → 详情 → 复习标记 | 「演示」视频 |
| R3 | 大模型对话流式 | 30–60s | 从详情页进对话 → 输入提问 → 展示流式输出、思考过程折叠、回到底部按钮；可顺带演示图片/文档附件 | 「演示」视频 / 「使用教程·AI 对话」 |
| R4 | 打印导出 | 30–60s | 列表勾选多题 → 生成 HTML → 系统「分享/打开」→ 浏览器打开 → 打印预览（或另存 PDF） | 「演示」视频 / 「使用教程·打印」 |
| R5（可选） | API 配置与连接测试 | 30–60s | 设置页填 Base URL + Key + 模型 → 点「获取模型列表」→ 测试通过/失败两种提示 | 「使用教程·首次配置」/「API 规格」 |

## 三、建议的提交顺序

录屏与截图建议按以下顺序产出并命名，方便对应占位符：

1. `R1 安装` → 2. `R2 功能总览` → 3. `S1/S2/S3 录入链路` → 4. `S4/S5 识别与编辑` →
   5. `R3 对话` → 6. `R4 + S8/S9 打印导出` → 7. `S11 设置` → 8. `S12 API 示例` → 9. `S13 仓库页`

产出后：

- 录屏上传至 B 站 / YouTube（或仓库 `docs/media/`），把链接贴进 `README.md` 的「演示」章节；
- 截图放入 `docs/media/`（或图床），替换「演示」章节的截图占位符；
- 如截图较多，建议在 README 用 2–4 张精选图 + 「更多截图见 docs/media/」的折叠块。
